# techlog-ui

[techlog](https://github.com/choigonyok/techlog)의 화면입니다. Create React App과 React Router(데이터 라우터)로 만들었고, [tech.choigonyok.com](https://tech.choigonyok.com)에서 Cloudflare Worker(부모 저장소의 `worker/`)가 이 빌드를 정적 자산으로 내보냅니다.

## 실행

API 는 같은 출처의 `/api/*` 를 부릅니다. 로컬에서는 부모 저장소의 Worker 를 띄웁니다.

```bash
npm install
npm run build                       # build/ — Worker 가 이 폴더를 정적 자산으로 쓴다
(cd ../worker && npm install && npm run dev)   # 화면과 API :8787 (처음이면 ../worker/README 의 '로컬 데이터')
npm start                           # 고치면서 볼 때. :3000 의 /api 요청을 :8787 로 넘긴다(package.json proxy)
npm test                            # 순수 로직 단위 시험(Jest)
```

다른 곳의 API 를 쓰려면 빌드할 때 `REACT_APP_HOST=https://…` 를 줍니다.

### E2E 시험(Cypress)

```bash
npm run build && (cd ../worker && npm run dev)          # :8787
CYPRESS_ADMIN_TOKEN=$(cd ../worker && node scripts/dev-token.mjs) npm run e2e
```

VS Code 터미널처럼 `ELECTRON_RUN_AS_NODE` 가 켜진 곳에서는 `env -u ELECTRON_RUN_AS_NODE` 를 앞에 붙입니다. 관리 화면 시험은 토큰이 있을 때만 돕니다.

## 구조

```

  api.js         글 목록·방문 수(첫 화면)   postApi.js 글 한 편·그림 주소   adminApi.js 쓰기·로그인
  components/    레이아웃(머리 막대·바닥글·테마·스크롤 기억·포커스), 기록 그림(Record), 주제 거르기(TopicNav),
                 글 목록, 글 머리, 본문 렌더러(Prose), 목차, 아이콘, 확인창, 오류 안내
  pages/         홈, 글, 로그인, 콜백, admin/(관리 목록·글쓰기·썸네일 고르기)
  lib/           기록 자료(timeline), 주제, 날짜·달 묶음, 찾기, 읽는 시간, 앞뒤·관련 글, 테마,
                 글자 수, 본문 트리 처리, 임시 저장
  styles/        색·글꼴·간격 토큰(tokens.css)과 기본 스타일(base.css), 색 대비 시험(tokens.test.js)

public/favicon.svg  사이트 표시(계단)의 원본. favicon.ico·logo192.png·logo512.png 는 이 그림에서 만들었다
cypress/e2e/     주요 흐름 E2E 시험
```

## 디자인 원칙

- **눈에 띄는 것은 기록 그림 하나입니다.** 소개 문장("꾸준함이란 도구로 성장하기를…")을 그대로 그렸습니다. 아래 한 줄은 주마다 쓴 글(꾸준함), 위의 계단선은 그때까지 쌓인 글 수(성장)입니다. 주제를 고르면 그 주제의 글만 밝힙니다. 글이 늘어 칸이 화면에 다 들어가지 않으면 달·분기·해로 묶고, 오래 쉰 기간은 한 칸짜리 쉼으로 접습니다(`lib/timeline.js`).
- **모든 화면이 같은 뼈대입니다.** 위에는 판(초록 바탕)의 쪽 머리가 이 화면이 무엇인지 말하고, 아래 종이 바탕에 내용이 놓입니다. 넓은 화면(1024px 이상)에서는 본문 옆에 레일이 서고(홈은 주제, 글은 목차), 좁은 화면에서는 같은 것이 위에 붙는 막대가 됩니다. 머리 막대·제목·본문은 모두 같은 왼쪽 선에서 시작합니다.
- **색은 초록 한 계열입니다.** 판(`--field`)은 사이트가 말하는 자리, 종이(`--paper`)는 사람이 쓴 글, 코드 판(`--code`)은 코드입니다. '지금 고른 것·지금 값'은 판 위에서 민트(`--signal`), 종이 위에서 왼쪽 막대(`--mark`)와 굵은 글자로만 표시합니다(고른 주제, 지금 읽는 절, 고른 썸네일, 기록 그림의 선). 두 번째 강조색은 없습니다. 짝마다의 명도 대비는 `styles/tokens.test.js` 가 지킵니다.
- **글꼴은 가변 글꼴 두 벌입니다.** Wanted Sans 한 벌로 본문(400)부터 큰 제목(800)까지 쓰고, 코드는 JetBrains Mono(이음자 끔)입니다. 한글은 유니코드 구간별 조각이라 화면에 나온 글자의 조각만 받습니다.
- 글 목록은 달마다 묶습니다. 넓은 화면에서는 달 이름이 왼쪽에 서서 그 달의 글을 따라 내려옵니다.
- 본문 글줄은 넓은 화면에서 18px, 한 줄 약 38자(`--measure`)이고, 한국어는 어절 단위로 줄을 바꿉니다(`word-break: keep-all`). 코드·그림·표는 그 폭에 묶이지 않고 본문 칸 끝까지 넓게 씁니다. 그림은 누르면 크게 봅니다.
- 주제는 쿠버네티스 레이블처럼 소문자로 보입니다. 대소문자만 다른 태그(`ISTIO`, `istio`)는 한 주제로 묶습니다. 주제(`?tag=`)와 찾는 말(`?q=`)은 주소에 남습니다.
- 밝은 화면·어두운 화면은 시스템 설정을 따르고, 머리 막대의 버튼으로 바꾸면 이 브라우저에 기억합니다(`lib/theme.js`, 첫 그림 전의 적용은 `public/index.html`).
- 손가락으로 누르는 요소는 44px 이상입니다(마우스가 주 입력이면 36px). 글줄 높이를 바꾸지 않아야 하는 곳은 누르는 영역만 넓힙니다.
- 움직임은 처음 한 번, 기록 그림의 선이 그려지고 칸이 켜지는 것뿐입니다. 시스템의 '동작 줄이기'를 따릅니다.
- 첫 화면은 gzip 기준 JS 77KB·CSS 19KB 안팎입니다. 홈 묶음에 코드를 더하면 바로 늘어나니, 다른 화면에서만 쓰는 코드는 그 화면 모듈에 둡니다.

## 관리 화면

- 글쓰기는 `/admin/write`, 고치기는 `/admin/posts/:id` 입니다. 제목·부제는 40자까지이고 글자 수를 보여 줍니다.
- 썸네일은 추가한 이미지 가운데 직접 고르며, 고른 한 장만 올라갑니다.
- 본문 그림은 `![설명](https://…)` 처럼 주소로 넣으면 저장할 때 서버가 내려받아 R2 에 옮겨 둡니다.
- 미리보기는 글 화면을 줄여 놓은 모양(판 위의 머리, 종이 위의 본문)이고, 본문 폭이 글 화면과 같습니다.
- 새 글은 이 브라우저에 임시 저장되고, 저장하지 않고 나가려 하면 확인을 받습니다.
